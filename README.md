# homebrew-tap

```bash
brew tap t1mdotcom/tap
```

## Formulae

| Name              | Beschreibung                                                     | Install                          |
| ----------------- | ---------------------------------------------------------------- | -------------------------------- |
| `yt-playlist-mp3` | Lädt YouTube-Playlists als MP3 herunter (Wrapper um `yt-dlp`)    | `brew install yt-playlist-mp3`   |

## Casks

| Name        | Beschreibung                                   | Install                            |
| ----------- | ---------------------------------------------- | ---------------------------------- |
| `trace-mem` | On-device Push-to-Talk-Diktat für macOS        | `brew install --cask trace-mem`    |
